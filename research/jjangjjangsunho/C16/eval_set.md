```python
class LRUCache:
    """LRU(Least Recently Used) 캐시를 구현하시오.
    get(key): key가 존재하면 value를 반환하고, 없으면 -1을 반환.
    put(key, value): key-value를 저장. 용량 초과 시 가장 오래 미사용된 항목 제거.
    모든 연산은 O(1) 시간이어야 한다.
    
    >>> cache = LRUCache(2)
    >>> cache.put(1, 1)
    >>> cache.put(2, 2)
    >>> cache.get(1)       # returns 1
    >>> cache.put(3, 3)     # evicts key 2
    >>> cache.get(2)       # returns -1
    >>> cache.put(4, 4)     # evicts key 1
    >>> cache.get(1)       # returns -1
    >>> cache.get(3)       # returns 3
    >>> cache.get(4)       # returns 4
    """
```
